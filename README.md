# Sahm Website

A responsive web app built with React and Tailwind CSS, integrated with a REST API using Axios.

🔗 **Live Demo:** [sahm-website-yugl.vercel.app](https://sahm-website-yugl.vercel.app)

## Tech Stack

- React
- Tailwind CSS
- Axios (REST API integration)
- CRACO
- Deployed on Vercel

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Yousef-Mohsen-Elmaady2005/Sahm-Website.git

# Install dependencies
cd Sahm-Website
npm install

# Run the development server
npm start

# Build for production
npm run build
```
